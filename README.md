# 🌱 Bot Ambiental

## 🚀 Funcionalidades

### 👋 `#ola`

Apresenta o bot ao usuário.

### 🌎 `#mudancas_climaticas`

Explica o que são mudanças climáticas, apresentando suas principais causas e consequências.

### 🗑️ `#lixo`

Mostra as cores utilizadas na separação de diferentes tipos de resíduos.

### 🌱 `#dica`

Envia uma dica ambiental escolhida aleatoriamente.

### 🎯 `#meta`

Gera uma meta ou desafio ambiental para o usuário realizar.

### 💡 `#curiosidade`

Envia uma curiosidade relacionada às mudanças climáticas.

### 🐾 `#fauna`

Apresenta exemplos de animais que podem ser afetados pelas mudanças climáticas.

### 🧠 `#quiz`

Inicia um quiz sobre mudanças climáticas utilizando um sistema separado de perguntas.

### 🌤️ `#clima [cidade]`

Consulta o clima atual de uma cidade utilizando a **WeatherAPI**.

São apresentadas informações como:

* 🌡️ Temperatura
* 🤔 Sensação térmica
* 💧 Umidade
* ☁️ Condição climática

### 📚 `#ajuda`

Mostra a lista de comandos disponíveis.

## 🔊 Síntese de voz

O projeto utiliza a biblioteca **pyttsx3** para transformar algumas respostas do bot em voz.

Dessa forma, comandos como `#dica`, `#meta`, `#curiosidade` e `#clima` podem, além de enviar uma mensagem no Discord, reproduzir a informação por áudio.
